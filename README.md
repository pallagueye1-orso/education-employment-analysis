# Education and Employment Analysis
A data analysis project exploring how education level influences employment and unemployment across countries using international data.

## Data
- data/ilo_cleaned_final.csv

## Data Description
The dataset comes from the International Labour Organization (ILO) and includes:
- country
- year
- education level
- employment rate

## Data Cleaning
We performed minimal cleaning to preserve as much information as possible.

## Objective
Analyze the impact of education level on employment and unemployment.

## Tools
- Python (pandas, matplotlib)
